# 我的第一個搜尋工具

一個可以在 **Mac 和 Windows 上都執行**的小型搜尋工具。
你在網頁輸入關鍵字 → 程式連上網路查資料 → 把結果顯示出來。

> 完全沒有工程背景也沒關係。請照著下面的順序做，不要跳步驟。

---

## 這個工具長什麼樣子

啟動之後，你會在自己的瀏覽器看到一個搜尋頁面（只有你的電腦看得到，不會公開到網路上）。
輸入關鍵字、按搜尋，程式就會去維基百科查資料並列出結果。

維基百科只是**起點**，因為它免費、不需要申請帳號密碼。
等環境建好、你熟悉流程之後，要換成別的搜尋來源（Google、YouTube、新聞、商品價格…）只要改 `app.py` 裡的一小段就好。

---

## 第一步：安裝環境（只需要做一次）

請按照你**現在**用的電腦，選一份指南照著做：

| 你的電腦 | 看這份指南 |
|---|---|
| Mac | **[SETUP-MAC.md](SETUP-MAC.md)** |
| Windows | **[SETUP-WINDOWS.md](SETUP-WINDOWS.md)** |

兩台電腦都要用的話，就兩份都做一次（Mac 做一次、Windows 做一次）。
好消息是：**環境裝好之後，之後每天用的指令兩邊幾乎一模一樣。**

---

## 第二步：每次要用的時候

環境裝好後，日常只有三個動作。打開終端機（Mac）或 PowerShell（Windows），然後：

**Mac**
```bash
cd ~/專案/test0000
source .venv/bin/activate
python app.py
```

**Windows**
```powershell
cd $HOME\專案\test0000
.venv\Scripts\Activate.ps1
python app.py
```

然後打開瀏覽器到 **http://127.0.0.1:5000**

要結束的時候，回到終端機按 `Ctrl + C`。

---

## 這些檔案分別是什麼

| 檔案 | 作用 | 你以後會改嗎 |
|---|---|---|
| `app.py` | 程式主體。負責開網站、連上網路搜尋 | 會，這是主要戰場 |
| `templates/index.html` | 你看到的那個網頁長相（搜尋框、結果列表） | 會，想改外觀就改這裡 |
| `requirements.txt` | 這個專案需要哪些外掛工具 | 偶爾 |
| `.gitignore` | 哪些檔案**不要**上傳到 GitHub（例如密碼） | 很少 |
| `.venv/` | 這個專案專屬的工具箱，電腦自動產生 | 不要手動碰 |

---

## 四個你會一直看到的名詞

1. **終端機 / PowerShell** — 用打字下指令的黑視窗。工程師的遙控器。
2. **Python** — 程式語言。Mac 和 Windows 都能跑同一份程式碼，這是我們選它的原因。
3. **虛擬環境（`.venv`）** — 這個專案「專屬的工具箱」。
   好處：A 專案裝的東西不會弄壞 B 專案。所以每次要寫程式前都要先「啟動」它。
4. **Git / GitHub** — 存檔與同步。讓你在 Mac 寫的東西，回家用 Windows 接著改。

---

## 第三步：讓兩台電腦同步（重要）

**不要**用 USB 或 LINE 傳程式碼，很快就會兩邊版本不一樣、搞不清楚哪個是最新的。
正確做法是透過 GitHub：

在 Mac 改完東西後，上傳：
```bash
git add .
git commit -m "說明我這次改了什麼"
git push
```

回到家用 Windows，先下載最新版再開始改：
```powershell
git pull
```

> 第一次在新電腦上要先把專案抓下來，指令是：
> ```bash
> git clone https://github.com/natsunari/test0000.git
> ```
